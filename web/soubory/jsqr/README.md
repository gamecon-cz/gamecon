# jsQR 1.4.0

Rozpoznání QR kódu ze snímku kamery pro čtečku v Nastavení (`web/soubory/ctecka-qr.js`), jen v prohlížečích bez
vestavěného `BarcodeDetector` (Safari, Firefox). Načítá se až při spuštění čtečky.

- zdroj: `dist/jsQR.js` z balíčku npm `jsqr@1.4.0` (https://github.com/cozmo/jsQR), beze změny
